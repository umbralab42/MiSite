# Як редагувати сайт МІТС

Коротка шпаргалка для редакторів: де в адмінці (`/wp-admin/`) змінюється кожна частина сайту.

## Дві мови

Кожна сторінка, новина, викладач, слайд і картка існує окремо українською та англійською
(плагін Polylang). У списках адмінки є колонки з прапорцями:

- ✎ (олівець) під прапорцем — відкрити переклад;
- **+** — створити переклад, якого ще немає (WordPress одразу зв'яже його з українським записом).

Зверху в адмінці є перемикач «Показати всі мови / Українська / English» — він фільтрує списки.
Перемикач мов на сайті веде на переклад поточної сторінки; якщо перекладу немає — на головну
англійської версії.

## Що де змінюється

| На сайті | В адмінці |
|---|---|
| Пункти меню (шапка й підвал) | «Вигляд → Меню»: `main_menu_mits_ua` і `main_menu_mits_en`. Клас пункту `submenu-blue` / `submenu-orange` фарбує підменю. |
| Слайди вгорі головної | «Слайди головної»: рядки заголовка, розмір шрифту, градієнт, іконки соцмереж; фото — «Зображення» праворуч; порядок — поле «Порядок». |
| «Чому ми?», цифри, заголовки «Переваги», «Діяльність», блок «Якісне… IT-навчання», кнопка «Навчальна програма» | «МІТС: блоки → Головна» (поля UA і EN поруч). |
| Пункти «Переваги» | «Переваги». |
| Картки «Діяльність» (і «Навчання» на сторінці «Кафедра») | «Діяльність». |
| Новини | «Новини». Зображення — «Зображення» праворуч; дата — дата публікації. Позначка «Не показувати в списках» ховає новину зі списків, але сторінка лишається доступною. |
| Коментарі під новинами | «Коментарі». Кожен новий коментар з'являється лише після схвалення. |
| Викладачі | «Викладачі»: посада, ступінь, посилання «Наукові праці», предмети, опис, фото для сторінки викладача; фото для списку — «Зображення»; порядок — поле «Порядок». |
| Сторінка «Кафедра» | «Сторінки → Кафедра»: текст опису — основний вміст; траєкторії, посилання «Історія кафедри», слайд — поля під редактором. |
| «Про кафедру», «Загальний опис», «Голосування» тощо | «Сторінки», звичайний текст сторінки. |
| Сторінка «Вступ» | «Сторінки → Вступ»: текст під «Освітні рівні», відео YouTube, слайд. Кнопки рівнів — «Освітні рівні (Вступ)», питання — «FAQ (Вступ)». |
| Бакалаврат / Магістратура / Аспірантура (Вступ) | Текст у картці — сама сторінка; кроки, предмети НМТ, алгоритм, поради — запис у «Освітні рівні (Вступ)», що посилається на цю сторінку. |
| Сторінка «Освіта» | Опис, слоган, слайд — поля сторінки. Логотипи програм, нормативні документи, картки «Бакалавр / Магістратура / Аспірантура» з документами й кнопкою «Проголосувати» — «МІТС: блоки → Освіта». |
| Підсторінки «Освіти» | Текст сторінки (показується в картці під слайдом). |
| Сторінка «Наука» | «Сторінки → Наука»: усі блоки (IPST з афішами, Micro CAD з цифрами й напрямами, наукові гуртки, стартапи з картинками, конкурси з вкладками років) — поля під редактором. Англійська версія — сторінка «Research». Слайд — «МІТС: блоки → Наука». |
| Сторінка «Міжнародність» | «МІТС: блоки → Міжнародність»: фото, текст, посилання, цифри, курси, документи (UA і EN). |
| Адреса, телефони, e-mail, соцмережі, кольори іконок | «МІТС: блоки → Контакти». Карта — у вмісті сторінки «Контакти» (блок «Довільний HTML»). |
| Форма «Консультація» | «Контакт → Контактні форми»: «Консультація» (UA) і «Consultation» (EN). Тексти полів, повідомлення і **адреса, куди приходять заявки** (вкладка «Лист» → «Кому»). Заявки в базі не зберігаються. |
| Підписи інтерфейсу англійською («Learn more», «All News»…) | «Мови → Переклади рядків», група «МІТС». |
| Назва сайту англійською | «Мови → Переклади рядків», рядок «Назва сайту». |
| Логотип | «Вигляд → Налаштувати → Ідентичність сайту». Логотип у випадному меню під стрілкою — «МІТС: блоки → Контакти». |
| Кольори градієнтів заголовків слайдів | «МІТС: блоки → Слайдер». |

## Поради

- Посилання в полях можна вказувати повністю (`https://…`), відносно сайту (`/вступ/`) або якорем (`#ipst`).
- У списках (предмети, поради, документи, картки) рядки додаються кнопкою «+ Додати…»,
  переставляються стрілками ↑ ↓, видаляються ✕.
- Шаблон сторінки («Атрибути сторінки → Шаблон») визначає, які поля з'являться під редактором.
  Після зміни шаблону збережіть сторінку й перезавантажте редактор.
- Зображення додавайте через «Медіафайли»: так WordPress сам підготує зменшені копії.
- Нову сторінку англійською створюйте кнопкою **+** у колонці EN українського запису —
  так зберігається зв'язок для перемикача мов.
